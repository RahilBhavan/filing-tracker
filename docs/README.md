# Documentation index

This folder holds the measured results, provenance and evaluation records for the filing change tracker. Start with the current results.

- [Current measured results](v2-results.md): per-pair V1 and V2 counts on the 50 author labels, ranking coverage and known limits.
- [Completion audit](completion-audit.md): checks run on September 22, 2026 and the acceptance gates that remain open.
- [Source access and provenance](source-access.md): issuer download URLs, SEC accession numbers and the limits of DOCX and PDF conversion.
- [Walkthrough](walkthrough.md): a step-by-step comparison, review correction and code reading on the fictional Alder pairs.
- [Evaluation](evaluation.md): where the current and historical evaluation records live.
- [`real-benchmark.json`](real-benchmark.json): raw output of `python3 scripts/benchmark.py`, with code hashes, misses and timings.
- [`v2-verification.json`](v2-verification.json): check records from the September 21 V2 release.
- [`review-preview.png`](review-preview.png): screenshot of the review app on the Microsoft FY2023→2024 pair.
- [`v1/`](v1/evaluation.md): historical V1 evaluation on the fictional fixtures, with its [verification output](v1/verification.json).
- [`v2/`](v2/results.md): historical V2 release results, the original [labels](v2/labels/), and the [holdout freeze](v2/holdout-freeze.json) code hashes.
